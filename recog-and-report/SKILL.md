# recog-and-report 技能说明与使用指南 (优化版)

本技能旨在帮助 AI 助手识别特定的 Word（.docx）模板文件，解析其页边距、行间距、段落缩进、混合中英文字体等格式要求，然后在保留模板的封面表格、封底和分节符（以确保“封面无页码，正文有页码”等复杂排版不被打乱）的前提下，自动填充并编译生成高质量的论文或报告。

> [!TIP]
> **能力较弱或非编程型模型优化**：
> 本技能包含了一个**全自动化的编译脚本 `auto_generator.py`**。使用本技能的模型**不需要编写任何 python-docx 代码**，只需生成一个结构化的 JSON 数据文件（见下文 `content.json` 样例），然后通过命令行运行编译脚本，即可完美生成符合模板要求的 Word 文档。

## 使用工作流 (最简模式)

当用户要求根据某个 `.docx` 模板生成报告时，AI 助手只需执行以下三个步骤：

1. **构思内容**：按照用户要求撰写论文/报告的正文内容。
2. **输出配置文件**：将撰写的内容格式化输出为本地的临时 `content.json` 文件（格式见下节）。
3. **运行命令行编译**：
   在终端运行配套的自动化编译脚本：
   ```bash
   python3 /Users/jim./Vibecoding/recog-and-report/scripts/auto_generator.py \
     --template "模板文件.docx" \
     --content "content.json" \
     --output "生成的论文.docx"
   ```

编译脚本将自动扫描模板并完成：
* 自动匹配并覆盖封面的“题目表”（Table 0）与“个人信息表”（Table 1）。
* 自动识别并保留分节符段落（保持“封面无页码，正文起从第1页开始”的排版）。
* 自动生成带有点引线（`……`）和对齐页码的目录（放置在分节前，不带页码）。
* 自动以“中文字体宋体/黑体，英文字体/数字 Times New Roman”的混合字体写入正文，并应用“固定行距20磅”、“首行缩进两字”等严格规范。

## 数据配置结构 (content.json)

输出的 JSON 文件必须符合以下结构规范：

```json
{
  "title": "AI驱动创新与新质生产力发展的案例分析——以上汽通用五菱为例",
  "fields": {
    "学号": "2200300101",
    "姓名": "张三",
    "专业": "通信工程"
  },
  "toc": [
    {"text": "引言", "page": 1, "level": 0},
    {"text": "1  上汽通用五菱企业背景与数字化转型挑战", "page": 1, "level": 0},
    {"text": "  1.1  上汽通用五菱在汽车行业的定位与核心优势", "page": 1, "level": 1},
    {"text": "2  AI应用与战略目标：五菱的“智能柔性制造”实践", "page": 3, "level": 0},
    {"text": "参考文献", "page": 11, "level": 0}
  ],
  "body": [
    {"type": "h1", "text": "引言"},
    {"type": "p", "text": "汽车制造作为国家传统工业的支柱，其转型升级不仅关乎企业竞争力，更是构建新质生产力的关键维度..."},
    
    {"type": "h1", "text": "1  上汽通用五菱企业背景与数字化转型挑战"},
    {"type": "h2", "text": "1.1  上汽通用五菱在汽车行业的定位与核心优势"},
    {"type": "p", "text": "上汽通用五菱汽车股份有限公司成立于2002年，是由上汽集团、通用汽车及广西汽车集团三方合资组建..."},
    
    {"type": "pb"},
    {"type": "ref_title", "text": "参考文献"},
    {"type": "ref_item", "text": "[1]  肖海棠. 上汽通用五菱智能制造发展战略研究[J]. 汽车与配件, 2021, (12): 45-49."}
  ]
}
```

### 元素类型说明：
* `title`: 封面的大标题（自动以三号宋体加粗写入）。
* `fields`: 覆盖表格 1 中对应的字段（自动匹配第一列的标签，并在第三列写入）。
* `toc`: 目录项数组。`level` 为 `0` 表示一级目录，`1` 表示二级目录（二级目录会自动缩进）。
* `body` 元素类型 `type`：
  * `h1`: 一级标题（黑体四号，加粗，左对齐）
  * `h2`: 二级标题（黑体小四，加粗，左对齐）
  * `h3`: 三级标题（楷体小四，左对齐）
  * `p`: 正文段落（宋体小四，行距固定20磅，首行缩进两字）
  * `pb`: 强制分页符（Page Break）
  * `ref_title`: 参考文献标题（黑体四号，顶格）
  * `ref_item`: 参考文献单项（宋体五号，行距20磅，无缩进）
  * `app_title`: 附录标题（黑体四号，居中）

## 核心自动化编译脚本说明

自动化编译脚本 `auto_generator.py` 内部采用了**动态地标识别技术**：
1. **动态日期定位**：利用正则 `\d{4}年\d{1,2}月\d{1,2}日` 搜索整个文档的段落，动态确定封面的截止边界（即 `cover_end`）。
2. **动态分节定位**：扫描每个段落底层的 XML 元素，寻找含有 `<w:sectPr>`（分节符）的节点，将其标记为 `section_break` 边界。
3. **安全清理**：只清空封面日期与分节符之间的说明段落，以及分节符之后的所有段落，避免了破坏文档本身的 Section 页边距与页脚（页码）配置。
