# Monthly Accounting

处理月度账单，生成标准Markdown报告。

## 账单目录结构

```
G:\1_Knowledge\Obsidian\记账\五月\
├── 中国银行账单五月密码501002.pdf
├── 微信支付账单流水文件(...).xlsx
└── 支付宝交易明细(...).csv
```

密码通常在PDF文件名中（如"密码501002"）。

## 处理流程

### 1. 读取账单

读取目录下三个文件：
- **支付宝CSV** - GBK编码，表头在"交易时间,交易对方"行
- **微信XLSX** - 表头在"交易时间"行，共11列
- **中国银行PDF** - 密码在文件名中（如"密码501002"），用PyPDF2解析

运行 `scripts/process.py` 处理，输出合并报告到账单目录。

```bash
python scripts/process.py <月份目录> <年份> <月份>
```

示例：
```bash
python scripts/process.py G:\1_Knowledge\Obsidian\记账\五月 2026 5
```

### 2. 剔除退款和无效交易

自动剔除以下交易：
- **退款交易**：描述包含"退款"、状态为"退款成功"
- **交易关闭**：支付宝状态为"交易关闭"的交易
- **不计收支**：支付宝方向为"不计收支"的交易
- **已退款**：微信状态包含"退款"的交易
- **金额为0**：金额等于0的交易
- **重复交易**：同一天同一金额同一商户的交易

退款记录保留在报告中，但不计入统计。

### 3. 投资单独列出

投资类交易不计入支出，单独列出：
- 关键词：基金、定投、申购、理财、余额宝、零钱通

### 4. 自动分类

按以下规则分类支出交易：

| 分类 | 关键词/商户 |
|------|------------|
| 🏠 住宿/房租 | 房租、水电费、房东 |
| 🛵 吃饭-外卖 | 外卖、闪购、美团、饿了么 |
| 🍜 吃饭-正餐/食材 | 餐厅、烧烤、沃尔玛、超市 |
| 🧋 吃饭-奶茶/零食 | 奶茶、咖啡、饮料、1点点 |
| 👔 购物-服饰 | 衣服、裤子、鞋、NewDecay |
| 📦 购物-京东 | 京东 |
| 📦 购物-拼多多 | 拼多多 |
| 📦 购物-淘宝 | 淘宝、天猫 |
| 💰 支付宝小荷包 | 小荷包、公款吃喝 |
| 🚗 交通 | 充电宝、铁塔能源、滴滴 |
| 🎮 娱乐 | 游戏、会员、App Store |
| 💊 医疗健康 | 药、医院 |
| 📚 学习 | 书、打印、照相 |
| 📎 其他支出 | 以上都不匹配时 |

### 5. 半自动确认

不确定的分类列出供用户确认：
- 大额交易（>500元）
- 匹配"其他支出"的交易
- 无法识别的商户

### 6. 生成报告

参照 `references/report-template.md` 生成报告，保存到账单目录：
```
G:\1_Knowledge\Obsidian\记账\五月\5月账单逐笔明细.md
```

## 收入分类规则

- **生活费/转账收入**：家人转账（爸爸、妈妈）、朋友转账、生活费
- **其他收入**：红包、返现、退款（部分）

## 支付方式映射

- 来源为"银行" → 支付方式填"中国银行储蓄卡"
- 来源为"微信" → 支付方式留空
- 来源为"支付宝" → 支付方式根据实际填写（花呗、余额宝、账户余额等）
